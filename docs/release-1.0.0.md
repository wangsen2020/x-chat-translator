日期：2026-10-22。范围：本地 Git Flow 合并、1.0.0 标签与 ZIP；不推送远程、不提交商店。

## 已处理的问题

1. 关闭发送翻译仍拦截原生发送：已修复，关闭后正常发送原文。
2. 私信翻译失败无重试：已补重试按钮，失败时显示原文。
3. 发送超时后可能重复触发未完成请求：桥接层增加发送中锁，提示用户先核对会话。
4. X 主列缺失时可能访问空节点：增加挂载条件检查。
5. 缺少隐私、版本与打包说明：已补齐；安装包采用明确文件清单，排除测试、开发配置与旧安装包。

## 已知限制与后续优先级

- 高优先级：持续跟踪 X 内部发送入口变化。当前依赖 React 内部结构和压缩函数特征，无法保证 X 更新后的兼容性；检测不匹配会停止译文发送。
- 高优先级：翻译服务不可用/限流时只提示失败，没有备用服务。当前使用 Google Translate 网页接口，不具备服务等级保证。
- 中优先级：缓存为页面内存缓存，刷新后消失；暂不持久化私信内容。
- 中优先级：长文按长度分段，跨段语义可能影响翻译质量；目前不处理图片文字、视频字幕。
- 后续：插件界面多语言、翻译服务选择、更多真实页面布局回归、商店材料与独立隐私政策页面。上述不是本次本地 1.0.0 的交付承诺。

## Git Flow 与安装核对

从现有 `feature/x-chat-translator` 提交已验证代码，使用 Git Flow 完成功能合并到 develop；创建 `release/1.0.0`，将 manifest 更新为 1.0.0，完成发布到 master 并回合 develop，创建本地 `1.0.0` 标签。保留分支以便追溯。

加载包或项目目录后，在扩展管理页确认 1.0.0，刷新所有 X 标签页。再确认工具栏图标、弹窗设置、首页/帖子双语显示及自聊发送；不要向其他联系人发送验收内容。ZIP SHA-256 见安装包同名 `.sha256` 文件。
