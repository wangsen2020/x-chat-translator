X Chat Translator는 X 게시물을 읽고 다른 언어로 채팅할 수 있도록 돕는 확장 프로그램입니다. 원문을 유지하면서 번역문을 확인하고, 다이렉트 메시지는 번역을 미리 본 후 직접 전송할 수 있습니다.

채팅 번역
• X의 기본 채팅 입력창에 메시지를 입력하면 위쪽의 별도 미리보기 영역에 번역문이 표시됩니다.
• 번역을 확인한 뒤 Enter 키를 누르거나 보내기 버튼을 클릭하면 번역문이 전송됩니다. 전송에 성공하면 초안과 미리보기가 지워집니다.
• 받은 텍스트 메시지를 자동으로 번역하고 원문 표시 여부를 선택할 수 있습니다.
• 오른쪽 설정창을 접을 수 있으며, 보내는 언어는 대화별로 저장됩니다.

게시물 원문·번역 표시
• 홈, 추천 피드, 게시물 상세 페이지와 답글에서 원문 아래에 번역문을 표시합니다.
• 스크롤하면서 새로 보이는 텍스트 게시물을 번역합니다. 번역에 실패하면 다시 시도할 수 있습니다.
• 도구 모음 팝업에서 게시물 번역을 켜거나 끄고 읽을 언어를 선택할 수 있습니다.

지원 언어
인터페이스는 브라우저 언어에 따라 한국어, 영어, 중국어 간체, 라틴 아메리카 스페인어, 일본어로 표시됩니다. 번역 대상 언어는 한국어, 영어, 중국어 간체, 스페인어, 일본어, 프랑스어, 독일어, 포르투갈어, 아랍어, 러시아어입니다. 초안은 번역 서비스가 지원하는 언어로 작성할 수 있습니다.

사용 및 제한 사항
x.com에서 지원되는 텍스트 콘텐츠만 처리합니다. 이미지 속 텍스트, 동영상 자막 및 오프라인 번역은 지원하지 않습니다. 번역 품질과 이용 가능 여부는 번역 서비스에 따라 달라집니다. X의 변경으로 채팅 전송 기능이 영향을 받을 수 있습니다. 호환되는 전송 함수를 찾지 못하면 번역문 전송을 중지하고 초안을 유지합니다. 보내기 전에 번역문을 확인하세요. 보내는 메시지 번역을 끄면 X는 평소처럼 입력창의 원문을 전송합니다.

데이터 및 개인정보
각 번역 기능을 켜면 해당 게시물, 받은 메시지 또는 입력한 초안의 텍스트가 Google Translate로 전송됩니다. 확장 프로그램에는 개발자가 운영하는 데이터 서버나 분석 추적 코드가 없습니다. 설정은 브라우저에 로컬로 저장됩니다. 번역 캐시는 현재 페이지의 메모리에만 저장되며 새로고침하면 삭제됩니다. 번역 서비스에 제공하고 싶지 않은 콘텐츠에는 자동 번역을 켜지 마세요.

이 확장 프로그램은 X 또는 Google의 공식 제품이 아니며, 두 회사와 제휴하거나 보증을 받지 않았습니다.
